

**Embedded systems & hardware security engineer** · PhD, University of Huddersfield (2026)

I build and test low-power embedded systems — firmware, PCBs and the measurements that show whether they really work. My PhD developed hardware-rooted device authentication for LoRaWAN IoT nodes, combining SRAM Physical Unclonable Functions with RF fingerprinting on ARM Cortex-M0+ hardware.

- **Hardware:** KiCad schematic & PCB layout · board bring-up · oscilloscope validation
- **Wireless & RF:** LoRa/LoRaWAN · RTL-SDR capture · carrier-frequency-offset analysis
- **Digital design:** VHDL · Verilog/SystemVerilog *(in progress)* · Intel Quartus · ModelSim
- **Analysis:** Python (NumPy, pandas, scikit-learn, matplotlib)
